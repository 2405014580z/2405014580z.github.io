02

Things to keep straight

One send is not one receive.
TCP carries a stream of bytes. A receiver needs a way to find the beginning and end of each frame.
A domain is not a single fixed address.
DNS can return several addresses. A useful network record includes the query time and the address actually tested.
A timeout is still an observation.
A missing ping reply or traceroute hop needs an explanation. It does not, by itself, show that a website is offline.
